# Sigma Mu Public Chapter Website

Public-facing Phi Gamma Delta Sigma Mu website for Mississippi State University, built with HTML, CSS, JavaScript, GitHub Pages, and Supabase.

- [Live website](https://chandrewc.github.io/msu-fiji-public/)
- [Brother Network repository](https://github.com/chandrewc/msu-fiji-database)
- [Project handoff: architecture, access, publishing, and verification](docs/PROJECT_HANDOFF.md)

The chapter website is public. Website Manager and content editing require authorized accounts. Public website images and leadership data are separate from private Brother Network records and profile photos.

Frontend changes deploy through the configured GitHub Pages source. Database changes require reviewed Supabase migrations; committing SQL alone does not apply it. Never put private credentials in frontend source.
